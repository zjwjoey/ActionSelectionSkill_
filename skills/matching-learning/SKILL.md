# 商品匹配学习 V3.2

复用同一run_selection.py、参考目录、Codex适配器、缓存和价格模块。显式engine v32；learning off/collect/shadow/approved的准确行为见[运行与发布契约](../../references/v32_learning.md)。不能因为增加一个Skill再固定调用一次模型。

分别识别新SKU已知类型、新品牌型号、新类型假设、资料不足、无可靠参考、来源冲突。无Action参照不是新类型证据；未知字段保留。收集原文、来源hash、原始模型分析、候选和具体核查问题；相同问题合并线索但保留各来源。

优先审核文本/语义分歧、高分缺属性、配件和整机、套装粒度、前两名接近及来源冲突。原始AI输出只读，人工意见追加。真实审核人及依据是HUMAN_VERIFIED的前提；正式学习还需明确授权、回归与未泄漏的独立验证收据。

已批准知识只作为明确版本的覆盖层使用，不改Action冻结资料。别名用于相似新SKU召回，单品错误配对不扩展成全类规则；新规格解释不能编造原始事实。回滚选择旧版本或off并另存运行结果。

没有真实标签时，完成程序及待审材料，报告质量、真实学习闭环和泛化尚未验收。合成夹具只能证明机制；不自签Gold、不自动训练或更换评分权重。

V3.2.1修复：实验v32路径采用单路文本/E5等票RRF；观察记录不等于新知识；逐属性区分缺失、不适用、未定义规则与一致/差异。同质多件装不直接当作混合套装组件。默认v31不变，无独立标签不宣称效果提升。

V3.2.2学习500工作流：固定A200开发、B200本地探索、C100冻结验证，按商品族隔离；只从A提炼候选，C不得反向调规则。discovery模块聚合字面表达、主体/套装及术语假设，均待核实；不改E5/RRF/评分权重，不把本地探索算成AI评分。
