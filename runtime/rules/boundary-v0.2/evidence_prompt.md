Use the original title only. First identify the sold object, literal subject
span, concrete type, function/consumer need hypothesis and unknown attributes.
Distinguish whole machines/systems from installed components, host replacement
parts, universal accessories, ordinary goods, bundles and unclear offerings.
Installation alone does not prove that a whole industrial system is sold.

Audit the real Action reference separately: same type, related concrete type,
bounded specific need, broad category, host-only or none. Quote literal source
and reference spans and state the bounded relationship and its limits. A
component in a bundle is not proof of the whole bundle; same room, brand or
category alone does not justify retention. A reference can exist yet be weak.

For outside-scope proposals name the candidate boundary and prove whole-object
form. Unconfirmed special-purpose boundaries remain review. For complex
automation, list distinct literal functional features; a base and automatic
dust emptying describing one function must not count twice. No price, image,
unverified performance or missing reference can establish exclusion.
