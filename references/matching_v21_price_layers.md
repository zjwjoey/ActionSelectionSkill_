# V2.1 历史价格证据候选层

显式调用的研究模块；不替换 V1.4 默认入口，不改变 V2 原提示、评分、权重、关系、排名、严格 `comparable()` 或原 C 结果。

```powershell
python scripts/matching_price_review.py --v2-run <原V2绝对目录> --output work/<新的V21目录>
```

原目录必须有真实冻结样本、请求、A/B结果、ABC明细、审核60对、Amazon索引、Action来源和两份来源审计。先核验样本/请求/参照散列、权重及源工作簿hash，输出目录存在即拒绝覆盖。离线使用冻结检索索引，无模型调用，无新分类训练。

- L1：两侧分别检查正数价格、明确币种、快照日期、源文件hash、商品URL绑定，Action还要求原名绑定。保留促销证据，未知不假称非促销。
- L2：双方L1有效且原同类型/同款候选、售品字面依据有效，计算历史整包标价比。按同日、1–7日、8–30日、超过30日分层；不证明同款、等量、等质或价值高低。
- L3：L2之上，只有明确共同计量基础才计算每件、每升/100ml、每kg/100g。显式倍数与件数可换算；未知数量不默认为1。模糊总量/每件量、冲突、未确认套装粒度均拒绝换算。尺寸、容器容量、物流重量、颜色/功能/接口数不能当作商品销售数量。

解析器仅覆盖有清楚字面依据的格式，不覆盖所有商品语义。任何可计算值仍须保留规格、形态和日期限制；无法计算不等于不存在价格。L2类型仍基于旧AI候选，禁止称为独立事实标签。部分候选有效不意味着C完整公平排序已建立。

原60对固定保留，人工裁定与经营裁定为空。30条从原200条分层选择；补充字面主体查询在全10,037条中计算，保存所有原排名及补充排名、完整可搜索目录。候选增加不等于真实漏召回；同分边界另记，未取得独立事实和全库核验不计算Recall。

价格变化单独统计名义数值、币种证据、二者同时变化与不足观察。“经济涨跌无法判断”是可重叠标记，不能与互斥组相加。未知币种变成EUR不说明涨跌。

结果、原始价格、工作簿和完整排名只保存忽略的本地 `work/`。公开仓库仅通用代码、合成测试、匿名计数。运行状态和最终代码SHA在输出目录另存；不为报告追自身SHA反复提交。不自动合并或发起新实验。
